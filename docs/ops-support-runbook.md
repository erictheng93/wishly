# 客服工單處理手冊（營運）

給處理客服工單的營運人員。工單入口：後台 `/admin/support`（後台首頁「客服工單」）。

## 誰能處理

- **回覆並結案**：`support` 角色與 `admin`。
- **只能看**：`finance`、`moderator`，看不到「回覆並結案」按鈕。
- **授予 `support` 角色**：只有 `admin` 能改。後台首頁 →「使用者」分頁 → 搜尋對方（Email、名稱或帳號 ID）→「編輯角色」→ 勾選 `support`，並填寫原因。

## 怎麼知道有新工單

- **站內通知**：有人送出工單（會員或未登入都算），每位有效的 `support` 與 `admin` 會收到一則「有新的客服請求」，點開會到 `/admin/support`。
- **不會一張一則**：如果你還有一則「有新的客服請求」沒讀，之後進來的工單不會再通知你。讀過（點開或全部標為已讀）之後，下一張工單才會再通知。所以看到通知時，請到 `/admin/support` 看整個待回覆佇列，不要只處理一張。若兩張工單幾乎同時送出，偶爾會多收到一則，屬正常。
- **Email**：帳號有 Email 才寄。台北時間 09:00–21:00 會隨站內通知寄出；21:00–09:00 進來的，隔天 09:00 才寄。有開啟推播的裝置，推播時機與 Email 相同。站內通知不受影響，一定會立即出現。
- **後台首頁**：「客服工單」按鈕上的數字是目前待回覆的工單數。
- 通知內容不含工單內文與提出者，要進後台才看得到。

## 處理步驟

1. 開 `/admin/support`，預設就是「待回覆」，由舊到新排列，從最上面開始。狀態篩選另有「已結案」與「全部」（兩者都由新到舊；「全部」每列會標示待回覆或已結案，查某人過去的工單時用）。
2. 看工單脈絡：
   - 會員工單會顯示帳號 ID，帳號被停權時標「已停權」，錢包被凍結時標「錢包凍結」。
   - 有附清單時，會顯示清單標題與網址代碼（slug），被下架時標「已下架」。
   - 有附儲值單時，會顯示特店訂單編號（`T` 開頭）與付款狀態。
   - 若你有對應角色，會看到連結：「檢舉與處置」（moderator，連到檢舉處理頁的該使用者或清單）、「儲值紀錄」或「金流交易明細」（finance，連到金流後台交易明細並篩選這位使用者）。沒有該角色就不會顯示連結。
3. 需要其他角色處理的，先轉給對方（見下一節），處理完再回覆。
4. 按「回覆並結案」，寫回覆內容後送出。會員會收到站內通知，到客服頁看回覆。

## 依類別處理

| 類別 | 去哪裡看 / 處理 | 誰能實際處理 |
|---|---|---|
| 帳號（account） | **解除停權**：後台首頁「使用者」分頁搜尋帳號 ID →「解除停權」；或從工單的「檢舉與處置」進檢舉處理頁，按「解除停權」。兩者都要填原因。 | `moderator` 或 `admin`。被停權的是營運人員時只有 `admin` 能解除。 |
| 清單（wishlist） | **恢復下架清單**：從工單的「檢舉與處置」進檢舉處理頁按「恢復清單」；或後台首頁「清單搜尋」貼上清單 slug 搜尋 →「恢復上架」。 | `moderator` 或 `admin`。 |
| 付款（payment） | 金流後台 `/admin/finance` →「交易明細」，用工單上的特店訂單編號搜尋，或點工單的「金流交易明細」。拒付爭議（標記爭議、勝訴、敗訴扣回）在同一頁。現金退款在「現金退款」頁（`/admin/cash-refunds`）。 | `finance` 或 `admin`。 |
| 錢包（wallet） | **解凍錢包**：「點數錢包」頁（`/admin/wallets`），搜尋使用者 →「解凍」，要填原因。有未結清的拒付欠款時無法解凍，要先在「拒付欠款」頁（`/admin/wallet-debts`）結清或註銷。拒付爭議判定勝訴時，錢包若沒有其他爭議中的儲值單會自動解凍。 | `finance` 或 `admin`。 |
| 其他（other） | 依內容判斷。 | — |

`support` 角色自己做不到上述處置。需要時：

- 停權、清單下架 → 請 `moderator`（或 `admin`）處理。
- 付款、儲值、錢包、退款 → 請 `finance`（或 `admin`）處理。
- 角色調整、登入方式、兩步驟驗證重設 → 請 `admin` 處理。

轉交時給對方工單的帳號 ID（或清單 slug、特店訂單編號），不要轉貼對方的 Email 或工單全文到其他管道。

## 未登入工單

- 標「未登入」的工單只有聯絡 Email，系統**不會寄信**給對方。
- 處理方式：按「用 Email 回覆」，用客服信箱（support@wishly.tw）寄出回覆，再回後台按「回覆並結案」，把你回覆的內容記下來。
- 這個 Email **沒有經過驗證**，任何人都能填別人的 Email。回信時：
  - 不可透露這個 Email 有沒有註冊帳號，也不可透露任何帳號資料（名稱、狀態、餘額、清單、交易）。
  - 需要查帳號時，請對方登入後從客服頁重新送出，或在回信中提供帳號 ID（帳號 ID 也不代表本人，只能用來查詢，不可依此回覆帳號資料）。
  - 被停權而無法登入的人只能用這個表單：可以請他提供帳號 ID，轉給 `moderator` 判斷是否解除停權；回信只說已收到、會依提供的帳號 ID 審查，不說明帳號狀態與停權原因。

## 只能回覆一次

- 回覆後工單立即結案，對方不能在同一張工單裡回話。
- 需要對方補資料時，在回覆中寫清楚要補什麼（例如帳號 ID、儲值時間與金額、清單網址），並請對方補齊後重新送出一張。
- 同一人同時待回覆的工單有上限（會員 5 張、未登入同一 Email 3 張），請盡量一次處理完。

## 回覆內容注意事項

- 不放其他人的個資（Email、電話、地址、真實姓名）。
- 不透露捐助者身分：誰認捐、誰贊助、贊助多少，一律不說。
- 不承諾退款金額、退款時間或爭議結果，這些由 `finance` 確認後才算數。可以寫「已轉交金流同仁確認，結果會再通知」。
- 不透露處理人或其他營運人員的身分。

## 資料保留

- 已結案的工單在結案 365 天後自動刪除。
- 會員刪除帳號時，他的工單立即一併刪除。

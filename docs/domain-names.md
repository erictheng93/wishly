# 品牌網域候選（.com）

查詢日期：2026-10-14。以 Verisign RDAP（`https://rdap.verisign.com/com/v1/domain/<name>.com`）驗證，回 404 代表**目前未被註冊**。

> RDAP 只能確認「未註冊」。下單前請到 <https://www.cloudflare.com/domains/> 做最後確認，並留意是否為溢價域名。

## 命名條件

- 兩個短詞組合，7–9 個字母，好唸好拼。
- 不綁定「禮物」：除了願望清單，也要能延伸到救災、募資、物資集結。
- 已排除：`wishsync`、`wishify`（皆已被註冊）；`wishifytw` 雖可用，但易與 wishify 混淆且鎖定台灣。

## 備註

- 4–6 字母的英文單字與常見組合 `.com` 基本上已被註冊殆盡，才退到 7–9 字母的複合詞。
- 偏救災 / 非營利用途時，可考慮同時註冊 `.org` 版本以增加公信力。

# 01 用戶・受捐者（開心願清單的人）流程模擬

日期：2026-10-29　腳本：`apps/web/qa/role-flows/recipient.mjs`　結果：`apps/web/qa/out/role-flows/recipient.json`、截圖 `apps/web/qa/out/role-flows/recipient/<步驟ID>.png`

## 角色設定

- **阿美**：新手媽媽，寶寶滿月，用 Wishly 開「滿月寶寶清單」，把連結丟進親友群組，讓大家認捐、避免買重複；另有驚喜派對、好友限定、摯友限定、私人清單與眾籌（嬰兒推車）。
- 手機為主要裝置，也會在桌面編輯；不懂技術，靠畫面文字理解。
- 平台外建立的其他人（本流程專用帳號）：捐助者小明／小華、營運（發點、推進採購單、下架）、好友 ×3、路人、別人（權限測試）、拋棄帳號（刪帳）。

## 目標

1. 從零註冊到發佈第一份清單、拿到分享連結。
2. 清單、品項、封面、可見度設定都照預期生效，且匿名／好友／摯友／私人看到的結果正確。
3. 有人認捐／贊助後，能在進度頁掌握、標記送達、取消、處理眾籌採購。
4. 帳號與資料自主：個人頁、通知、匯出、登出入、忘記密碼、刪帳。

## 流程總覽

1. 帳號：首頁 → 註冊（OTP）→ 首次 dashboard（R-01～R-04）
2. 建清單：表單驗證、公開清單含封面／活動日／顯示暱稱／購買期限（R-05～R-06）
3. 品項：數量制、圖片、眾籌（含收件資訊）、編輯、排序、刪除、靈感目錄加入（R-07～R-12、R-30b）
4. 設定與發佈：改設定、樂觀鎖衝突、封面上傳、發佈與分享面板（R-13～R-15）
5. 分享頁：桌面、OG、SSR 時區、手機 390、創建者頁手機版、dashboard（R-16～R-18）
6. 進度與認捐：空狀態、製造資料、即時更新、公開頁暱稱、標已送達、取消、感謝（R-19～R-25）
7. 眾籌：贊助中、達標採購、達標後限制（R-26～R-28）
8. 變更通知：改品項、刪有認領品項（R-29～R-30）
9. 驚喜模式：遮蔽、鎖定、解鎖（R-31～R-33）
10. 好友與可見度：加好友、邀請連結、friends／selected／private、下架、動態、解除好友（R-34～R-40）
11. 生命週期：結束／重開、closes_at 自動結束、封存（R-41～R-43、R-56）
12. 帳號設定：名稱、個人頁、通知、密碼／裝置、匯出、登出入、忘記密碼、權限、語系、刪帳（R-44～R-55、R-57）
13. 無法驗證項目（R-58～R-63）

## 平台外動作（皆在步驟 note 註明）

取 OTP（Mailpit）、清除每 IP OTP 限流、以 API 建立其他角色帳號（含把營運帳號 `is_staff` 設 true，僅本流程專用帳號）、捐助者認捐／贊助、營運發點／推進採購單／下架（API）、`UPDATE event_date / closes_at`（時間快轉）、`UPDATE notifications.scheduled_at`（提前合併通知）、DB 唯讀查詢驗證。

## 環境註記（非產品問題）

- console 的 `403 FORBIDDEN` 來自 `localhost:9000`（moto 替身 S3 不開放公開讀取），已上傳的封面／品項圖在畫面上是破圖；上傳、confirm、處理狀態流程正常。
- 登入頁 `401 /me` 為未登入探測的預期回應；Chromium 原生驗證泡泡為英文，與產品無關。

### R-P1 分享頁結束時間 SSR 時區（中）
- 重現：建立公開清單並設 closes_at（台北 11/24 00:22）→ 匿名開 `/s/<slug>`；比對 SSR HTML 與瀏覽器 hydrate 後文字。
- 預期：皆為「2026年11月24日 凌晨12:22」。實際：SSR 為「2026年11月23日 下午4:22」（UTC），hydrate 後改成台北時間，console 出現 "Hydration completed but contains mismatches."（R-16b、R-44）。無 JS／爬蟲／首屏會錯 8 小時。
- 程式碼：`apps/web/app/pages/s/[slug].vue:213`（`toLocaleString` 未帶 `timeZone`）；`lists/[id]/progress.vue` 已用 `timeZone: 'Asia/Taipei'` 可對照。
- 建議：加 `timeZone: 'Asia/Taipei'`（或抽共用 formatter）。直接修。

### R-P2 顯示暱稱開關預設無效（中）
- 重現：開「顯示送禮者暱稱給其他訪客」→ 捐助者以預設設定認捐 → 匿名開分享頁（R-22）。
- 預期：顯示暱稱。實際：顯示「匿名」；捐助者把該筆認領改 public 後才顯示。claims.visibility 預設承襲捐助者的 default_claim_visibility（friends）。
- 程式碼：`apps/api/src/public.rs:276`（依 `c.visibility` 判斷，回應可被共用快取）；文案 `lists.json` `new.showNames`。
- 建議：開關旁說明「僅捐助者選擇公開時才顯示」，或調整認捐流程預設。產品決策，開 issue。

### R-P3 刪除已達標眾籌品項的訊息（低）
- 重現：眾籌達標並下單後，編輯頁按「刪除」→「刪除」（R-28）。
- 預期：直接告知「已達標並進入採購，無法刪除」。實際：先顯示「此品項已有人認領。若仍要刪除，認領將一併取消」，按鈕變「連同認領一併刪除」，再按才出現真正原因；API 直接 DELETE 回 409 `ITEM_HAS_CLAIMS`。
- 程式碼：`apps/web/app/pages/lists/[id]/edit.vue:108`；`apps/api/src/wishlists.rs:1880` 起。
- 建議：依 `funding_status`／API detail 顯示，已達標品項隱藏刪除鈕；眾籌文案用「贊助」。直接修。

### R-P4 參考價格不顯示（低）
